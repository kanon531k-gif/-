THE GRAND LINE LOG — 懸賞金ポスター風のONE PIECE進捗アプリ

初期値：78話 / 目標1180話
機能：話数入力、+1/+5/+10、達成率、残り話数、100話ごとの称号、メモ保存。

ホーム画面に追加する手順:
1. このZIP内のファイルをHTTPS対応の静的サイト公開サービスにアップロードして公開URLを作成。
2. iPhoneのSafariで公開URLを開く。
3. 共有ボタン →「ホーム画面に追加」。
4. ホーム画面の「航海記録」アイコンから起動。

注意：ZIPをダウンロードしただけではホーム画面アプリとして公開されません。公開先の設定が必要です。記録は同じ端末・同じブラウザ内に保存されます。
